# Aether AI — Landing Page

Profesjonalna strona marketingowa (B2B) dla firmy AI. Nazwa **Aether AI** jest placeholderem — można ją łatwo zmienić w komponentach i metadanych.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Uruchomienie

```bash
npm install
npm run dev
```

Aplikacja będzie dostępna pod [http://localhost:3000](http://localhost:3000).

## Build produkcyjny

```bash
npm run build
npm start
```

## Uwagi

- Brand name „Aether AI” jest placeholderem.
- Formularz kontaktowy działa po stronie klienta (walidacja + komunikat sukcesu) — bez backendu.

## Lockfile

Jeśli w repozytorium brakuje `package-lock.json`, wygeneruj go lokalnie:

```bash
npm install
```
